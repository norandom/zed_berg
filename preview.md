# Berg — market briefing

Amber body text on a black background.

## Headlines

*Cyan italic emphasis* and **blue bold emphasis**.

- Market activity and earnings
- Inline code: `market.close()`
- [Berg theme](https://github.com/jx22/berg)

> A quoted market update.

```javascript
// Berg syntax palette
function quote(symbol, price = 42) {
  const market = "OPEN";
  return { symbol, price, market, active: true };
}
```
